# 📱 جزوه‌ساز هوشمند اندروید و هاگینگ‌فیس (موتور Mix API)

سامانه ابری و همراه برای تولید خودکار جزوات آموزشی با هوش مصنوعی و API کلاد بر بستر معماری بهینه‌شده پروژه میکس، با قابلیت کنترل کامل از طریق مرورگر گوشی یا تبلت اندروید و اتصال به پیام‌رسان بله.

---

## 🌟 قابلیت‌های اختصاصی برای کنترل با گوشی (موبایل):

1. **ارسال فایل ورودی از گوشی**:
   - امکان بارگذاری مستقیم فایل‌های Word (`.docx`) یا متنی (`.txt` / `.md`) از حافظه گوشی یا تبلت بدون نیاز به کامپیوتر.
2. **دانلود فایل‌های خروجی روی گوشی**:
   - دانلود مستقیم فایل نهایی Word اصلی، Word تدریس خالص، کتاب‌خوان مدرن HTML و پایگاه‌داده با یک لمس.
3. **تنظیمات کامل روی موبایل**:
   - انتخاب مدل هوش مصنوعی (`Claude Sonnet 5.5`, `Opus`, `Gemini Pro` و...)
   - تنظیم میزان تفکر (Thinking: `low`, `medium`, `high`)
   - تنظیم اندازه قطعات (Chunk Size) و تاخیر بین درخواست‌ها
   - ویرایش پرامپت اصلی و قالب کانتکست
   - افزودن کلیدهای API تکی یا گروهی و فعال/غیرفعال کردن ارائه‌دهنده‌ها
4. **جلوگیری هوشمند از به خواب رفتن سرور (Anti-Sleep) و اتصال به ربات بله**:
   - **سلف پینگ خودکار**: پینگ دوره‌ای به خود سرور جهت بیدار ماندن در هاگینگ‌فیس.
   - **اتصال به بات بله**: امکان ارسال دستور `/status` یا `/ping` در پیام‌رسان بله برای بیدارباش سرور.
   - **ارسال خودکار فایل خروجی**: ارسال مستقیم فایل نهایی Word به چت یا کانال بله شما پس از اتمام تولید.

---

## 🚀 راهنمای استقرار سریع و رایگان در Hugging Face Spaces:

1. وارد سایت [Hugging Face](https://huggingface.co) شده و یک اکانت بسازید (یا لاگین کنید).
2. به بخش **Spaces** بروید و دکمه **Create new Space** را بزنید.
3. یک نام برای اسپیس خود انتخاب کنید (مثلاً `jozve-saz`).
4. در بخش **Space SDK**، گزینه **Docker** (Blank) را انتخاب کنید.
5. حالت Space را روی **Public** (عمومی) یا **Private** (خصوصی - کاملاً رایگان) قرار دهید و دکمه **Create Space** را بزنید.
6. تمامی محتویات پوشه `Android Jozve` (شامل `Dockerfile`, `server.py`, `requirements.txt`, پوشه‌های `core`, `static`, `config` و...) را از طریق Git یا با دکمه **Add file -> Upload files** داخل مخزن آپلود کنید و Commit بزنید.
7. هاگینگ‌فیس در کمتر از ۲ دقیقه برنامه را Build و Run می‌کند و یک لینک به شما می‌دهد (مانند `https://username-jozve-saz.hf.space`).
8. این لینک را در مرورگر کروم گوشی اندروید خود باز کنید و از کار با برنامه لذت ببرید! (می‌توانید گزینه «افزودن به صفحه اصلی / Add to Home screen» را بزنید تا مثل یک اپلیکیشن بومی اجرا شود).

## 🤖 نحوه تنظیم ربات بله برای جلوگیری از خواب و دریافت فایل:

1. در پیام‌رسان بله به بات‌فادر بله (`@BotFather`) بروید و با دستور `/newbot` یک ربات بسازید و توکن آن را کپی کنید.
2. آیدی عددی چت یا کانال خود را دریافت کنید.
3. در فایل `config/settings.json` (یا از داخل تنظیمات برنامه)، مقادیر زیر را قرار دهید:
   ```json
   {
     "space_url": "https://username-jozve-saz.hf.space",
     "enable_keepalive": true,
     "keepalive_interval_minutes": 12,
     "bale_bot_token": "توکن_ربات_بله",
     "bale_chat_id": "آیدی_چت_شما",
     "enable_bale_notifications": true
   }
   ```
4. با این تنظیم:
   - سرور هر ۱۲ دقیقه پینگ می‌شود تا نخوابد.
   - با ارسال دستور `/status` در بله، پیشرفت زنده پروژه را مشاهده می‌کنید.
   - فایل نهایی ورد جزوه پس از پایان تولید، مستقیماً به پیوی بله شما ارسال خواهد شد!
